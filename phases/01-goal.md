# Goal — починить чат в Ruslan Agent

## Проблема
Чат в приложении не работает:
1. Нет истории сообщений (RecyclerView отсутствует)
2. Ввод текста есть, но отправка ничего не делает
3. Нет соединения с Hermes gateway
4. Весь UI "сыроватый" — нет списка сообщений, адаптера, модели данных

## Что нужно сделать
1. Добавить RecyclerView для отображения сообщений
2. Создать Message data class + MessageAdapter
3. Реализовать отправку: ввод → отправить в gateway → показать в чате
4. Загрузить историю сообщений при открытии чата
5. Терминальный стиль для сообщений (зелёный текст на чёрном, как ruslan.team)

## Критерий успеха
Пользователь печатает сообщение → оно появляется в чате → ответ от Hermes gateway приходит и отображается
