# 01-goal.md

## Цель: Сделать чат рабочим + выбор модели в визарде

### Критерии готовности
1. **Чат работает**: отправка "привет" → ответ от DeepSeek (или любого провайдера)
2. **Выбор модели в визарде**: после провайдера → список моделей → API-ключ
3. **Telegram-бот**: запускается из настроек
4. **Кнопки в диалогах**: чёрный текст (не зелёный)

### Non-goals
- Release APK (без signing key)
- Шифрование ключей
- История чата (Room)
- Статистика на главной
