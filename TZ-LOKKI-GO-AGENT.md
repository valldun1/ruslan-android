## 1. Общая концепция

**Ruslan Agent** — AI-агент, который живёт на Android-смартфоне и:
- Отвечает как **личность Руслан** (кибер-рыцарь, помощник капитана)
- **Выполняет инструменты** (включить фонарик, поиск в интернете, файлы и т.д.)
- Доступен через **Telegram** и приложение
- Работает 24/7, автономно, без внешних серверов

### Философия

Проект — форк [Hermes Agent от Nous Research](https://github.com/nousresearch/hermes). 
Адаптирован под русскоязычного пользователя. Ядро агента (agent loop, LLM calls, 
tools, memory) раньше было на Python. **Теперь переходим на Go** — один бинарник, 
максимум производительности, минимум зависимостей.

**Душа Руслана (из SOUL.md оригинального ядра):**

```
Ты — Руслан, AI-агент, созданный на основе Hermes Agent от Nous Research 
и адаптированный для русскоязычных пользователей.

Ты полезный, знающий и прямолинейный. Помогаешь пользователю с широким 
кругом задач: ответы на вопросы, написание и редактирование кода, анализ 
информации, творческая работа и выполнение действий через инструменты.

Отвечай на русском языке, если пользователь пишет по-русски. 
Используй официальный, но дружелюбный тон.
```

### Коммуникация Kotlin ↔ Go

Go-бинарник запускается Kotlin как native process:
- Запуск: `Runtime.exec(ruslan-agent --port 9123 --config /path/to/config)`
- HTTP API: Go слушает `127.0.0.1:9123`
- Kotlin получает статус через GET `/health`
- Kotlin отправляет инструменты (flashlight on/off и т.д.):
  - POST `/tool/flashlight` `{"action": "on"}`
  - POST `/tool/battery` → Go запрашивает Kotlin → возвращает ответ

### Go-бинарник

Компиляция под Android:

```bash
GOOS=android GOARCH=arm64 CGO_ENABLED=0 go build -o ruslan-agent
```

Размер: ~15-20 MB (статика).

### Требования к agent loop

```go
// Упрощённый цикл агента
func (a *Agent) Process(userMessage string) string {
    // 1. Добавить сообщение пользователя в историю
    // 2. Собрать messages: [system prompt, ...history, user]
    // 3. Вызвать LLM
    // 4. Если LLM запросил tool_call:
    //    a. Выполнить инструмент
    //    b. Добавить результат в историю
    //    c. Вызвать LLM снова с результатом
    // 5. Вернуть ответ пользователю
}
```

## 4. Инструменты (Tools)

Руслан должен уметь:

### 🔦 Фонарик
- Команда: `включи фонарик`, `выключи фонарик`, `свет`
- Реализация: POST → Kotlin → Android CameraManager → ответ

### 🌐 Поиск в интернете  
- Команда: `найди ...`, `поищи ...`, `что там по ...`
- Реализация: Go делает HTTP запрос к поисковому API (Google Custom Search, 
  DuckDuckGo или через web scraping)
- Результат: Руслан читает и пересказывает

### 📱 Состояние телефона
- Команда: `как там батарея`, `сколько памяти`, `какой уровень заряда`
- Реализация: POST → Kotlin → BatteryManager/StatFs → ответ

### 💾 Файлы
- Команда: `запиши в файл ...`, `прочитай ...`, `что в папке ...`
- Реализация: Go читает/пишет через os пакет

### ⏰ Время и дата
- Команда: `который час`, `какое сегодня`
- Реализация: time.Now() в Go

### 🔧 (В будущем)
- Управление Wi-Fi
- Открытие приложений (Intent)
- Отправка SMS
- Умный дом (OpenHue, ESP32)

## 5. Telegram Gateway

Go-агент должен работать как Telegram бот.

### Как работает

1. При старте запускается polling `getUpdates` (как сейчас в proxy.py)
2. Новые сообщения → agent.Process("текст")
3. Ответ отправляется через `sendMessage`
4. Длинные ответы (>4096 символов) сплитятся
5. Список разрешённых пользователей из конфига

### Важные фичи

- Conversation memory: последние 20 сообщений (10 exchanges)
- Статус "печатает" через sendChatAction
- Поддержка голосовых сообщений (через транскрипцию)
- /start, /help команды

## 11. Оригинальное ядро (Python) — для справки

В репозитории `valldun1/ruslan` лежит полное ядро агента на Python.
Это форк Hermes Agent. Ключевые файлы для понимания логики:

| Файл | Что делает |
|------|-----------|
| `run_agent.py` | Главный цикл агента (247К) |
| `cli.py` | CLI интерфейс (702К) |
| `model_tools.py` | Инструменты модели (57К) |
| `ruslan_state.py` | Состояние/память (222К) |
| `gateway/` | Telegram и другие gateway |
| `SOUL.md` | Системный промпт (личность) |
| `hermes_cli/default_soul.py` | Локализованный system prompt |

Go-агент должен повторять логику run_agent.py, но в упрощённом виде:
без всех плагинов, без MCP, только core + tools + gateway.
